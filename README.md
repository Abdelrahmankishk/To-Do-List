# To-Do List — JavaScript

A **JavaScript-based To-Do List Application** that allows users to manage daily tasks through CRUD operations. This project focuses on practicing JavaScript fundamentals, including arrays of objects, DOM manipulation, event handling, Regular Expressions, and Local Storage, through an interactive task management application.

## 📌 Project Overview

The To-Do List application is a task management website built to practice core JavaScript concepts and understand how JavaScript handles data and dynamically interacts with HTML elements through the DOM.

The application stores tasks as objects inside an array, with each task having a unique ID and text. JavaScript handles task creation, display, editing, completion, and searching, while Local Storage preserves the tasks between page visits and browser refreshes.

HTML and CSS are used to structure and style the interface, while Bootstrap provides UI components such as the edit modal. JavaScript handles the application's main functionality and logic.

## ✨ Key Features

- **Create Tasks:** Add new tasks with input validation before saving them.
- **Display Tasks:** Dynamically render tasks from an array of objects.
- **Edit Tasks:** Update existing tasks using a Bootstrap modal.
- **Complete Tasks:** Remove completed tasks from the active list with CSS animations.
- **Search Tasks:** Filter tasks instantly using case-insensitive partial-text matching.
- **Input Validation:** Validate task inputs using Regular Expressions to prevent empty or whitespace-only tasks.
- **Local Storage:** Save tasks locally and restore them after refreshing the page.
- **Dynamic DOM Manipulation:** Create, update, and remove HTML elements dynamically without reloading the page.
- **Empty State Handling:** Display an informative message when no tasks match the current list or search.
- **Responsive Design:** Adapt the interface to different screen sizes.
